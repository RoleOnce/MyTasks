# To-Do-appen

Ett litet React-projekt (byggt med Vite + Tailwind CSS).

## Kom igång lokalt

1. Installera [Node.js](https://nodejs.org) (välj LTS-versionen) om du inte redan har det.
2. Öppna en terminal i den här mappen och kör:

   ```bash
   npm install
   npm run dev
   ```

3. Öppna länken som visas i terminalen (oftast `http://localhost:5173`) i din webbläsare.

## Publicera på nätet

1. Pusha den här mappen till ditt GitHub-repo.
2. Skapa ett gratis konto på [vercel.com](https://vercel.com) eller [netlify.com](https://netlify.com).
3. Koppla kontot till ditt GitHub-repo och klicka på "Deploy" (inga extra inställningar behövs, Vite känns igen automatiskt).
4. Du får en riktig länk, t.ex. `dintodoapp.vercel.app`.
5. Öppna länken i Safari på iPhone → tryck på dela-ikonen → "Lägg till på hemskärmen".

## Data

Uppgifterna sparas i webbläsarens `localStorage`, så de finns kvar mellan besök på samma enhet.
